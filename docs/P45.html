Partie 4 : Décodage & Logique d'Acheminement (Vrai ou Faux)

Coche Vrai ou Faux pour chaque affirmation, puis justifie brièvement ta réponse.

3 points

1. « Deux ordinateurs connectés sur le même réseau peuvent avoir exactement la même adresse IP. »

Justification :

🔑 FAUX — Chaque appareil doit avoir une adresse IP unique (comme une adresse postale) pour éviter les conflits.

2. « Sans l'adresse IP de destination écrite sur l'enveloppe, le Switch et le Routeur ne savent pas où envoyer le paquet. »

Justification :

🔑 VRAI — L'adresse IP de destination est indispensable pour aiguiller le paquet sur le bon fil.

3. « Un Switch sert uniquement à connecter notre classe à des serveurs situés dans un autre pays. »

Justification :

🔑 FAUX — C'est le Routeur qui relie différents réseaux distants ; le Switch connecte les appareils d'un même réseau local.

4. « Si plusieurs paquets d'un même message prennent des chemins différents, ils peuvent arriver dans le désordre. »

Justification :

🔑 VRAI — Certains trajets sont plus longs ou encombrés ; le destinataire utilise les numéros (1/3, 2/3, 3/3) pour les trier.
